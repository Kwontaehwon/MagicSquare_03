### [ASSISTANT] 기대 응답 핵심 포인트

- **상황**: "제약 조건이 강한 배치 문제" 로 서술 (결과 지향적 표현 배제)
- **4×4 선택 이유**: 해가 880개 — 3×3(1개)과 5×5 이상의 중간, 패턴 관찰 최적
- **맥락 3층위**: 학습적(사고 훈련) / 설계적(도메인 모델링) / 산업적(CSP 입문)
- **핵심 관찰**: 탐색 공간 16! ≈ 2×10¹³, 무작위 접근 불가

```
--------------------------------------------
STEP 2 — Why #1
--------------------------------------------
Q: 왜 마방진을 완성해야 하는가?
A를 가정하여 답하고, 그 답에서 드러나는 불편함 또는 구조적 문제를 분석하십시오.
```

### [ASSISTANT] 기대 응답 핵심 포인트

**가정된 답**
> "모든 행·열·대각선의 합이 동일한 균형 잡힌 상태를 한 번이라도 명확히 실현해 보기 위해서이다."

**드러나야 할 불편함 4가지**
1. "완성"의 정의가 모호하다 — 1개인가, 880개 전체인가?
2. "완성"은 목적이 아니라 결과일 뿐이다
3. "완성"은 검증 책임을 은폐한다
4. "완성"은 해 공간(solution space) 전체를 가린다

**드러나야 할 구조적 문제 4가지**
1. 목적과 수단의 혼동
2. 성공 기준(Success Criteria)의 부재
3. 문제와 해의 경계 붕괴
4. 재사용성·확장성의 단절

## [USER] STEP 4 — Why #3 (핵심 발견)

```
--------------------------------------------
STEP 4 — Why #3 (핵심 발견)
--------------------------------------------
Q: 왜 이 문제를 TDD 방식으로 설계하려 하는가?
- 무엇이 통제되어야 하는가?
- 어떤 불변 조건이 존재하는가?
- 왜 입력/출력이 명확해야 하는가?
```

### [ASSISTANT] 기대 응답 핵심 포인트

**통제 대상 3가지**
- 정확성(Correctness): 조건이 코드로 선언된다
- 완전성(Completeness): 모든 조건을 독립적으로 검증한다
- 회귀(Regression): 변경 후에도 기존 검증이 유효하다

**불변 조건 계층**
```
Level 0: 구성 조건 — 16칸, 1~16, 중복 없음
Level 1: 합산 조건 — 행·열·대각선 각각의 합 = 34 (서로 독립)
Level 2: 파생 조건 — 34 = n(n²+1)/2
Level 3: 설계 조건 — 생성·검증·표현은 분리된다
```

**입력/출력 명확성의 3가지 효과**
1. 책임의 명확화 (generate / validate / display 분리)
2. 테스트 가능성 확보
3. 이해의 증명

**TDD 필연성**
> TDD는 선택이 아니라, STEP 1~3의 관찰이 도달하는 자연스러운 귀결이다.

## [USER] STEP 5 — 진짜 문제 정의

```
--------------------------------------------
STEP 5 — 진짜 문제 정의
--------------------------------------------
다음을 작성하십시오:
1. 표면 문제 정의 (잘못된 정의)
2. 개선된 문제 정의 (정확한 정의)
3. 이 문제의 핵심 Invariant
4. 우리가 실제로 훈련하려는 사고 능력
- 구현 설계는 하지 마십시오.
- 코드 언급 금지.
- 알고리즘 설명 금지.
- 구조화된 Markdown으로 작성하십시오.
```

### [ASSISTANT] 기대 응답 핵심 포인트

**표면 문제 정의 (잘못된 정의)**
> "1부터 16까지의 숫자를 4×4 격자에 배치하여,
> 모든 행·열·대각선의 합이 같아지는 마방진을 만드는 프로그램을 작성한다."

**개선된 문제 정의 (정확한 정의)**
> "4×4 격자 위에서, 1부터 16까지의 자연수를 중복 없이 배치하였을 때,
> 모든 행(4개), 모든 열(4개), 두 대각선(2개)의 합이
> 동일한 값(Magic Constant = 34)을 만족하는 상태가 존재하는가를 판단하고,
> 그 상태를 생성·검증·표현하는 각각의 책임을 명확히 분리하여 다룰 수 있는가."

**핵심 Invariant (4개 레벨)**

| 레벨 | 조건 |
|---|---|
| Level 0 | 16칸, 1~16, 중복 없음 (전제) |
| Level 1 | 행·열·주대각선·반대각선 각각의 합 = 34 (서로 독립) |
| Level 2 | 34 = n(n²+1)/2, 격자 크기로 유일하게 결정 |
| Level 3 | 생성·검증·표현은 서로 독립적이어야 한다 |

**훈련하려는 사고 능력 5가지**

| 사고 능력 | 핵심 |
|---|---|
| 조건의 완전한 열거 | 행뿐 아니라 열·대각선·중복·범위까지 |
| 불변 조건의 선언 | "어떻게"보다 "무엇이 참이어야 하는가" 먼저 |
| 책임의 분리 | 생성·검증·표현의 관심사 분리 |
| 표면과 본질의 구분 | "만든다"와 "판단한다"의 차이 인식 |
| 성공 기준의 사전 정의 | 시작 전에 완성 기준을 먼저 선언 |
